# XRD Workbench v1.3.0 — 2026-11-06

## 更新内容

- 補助パネルはIgor内で選択しやすい表示を保ち、他のWindowsアプリへ切り替えると隠れます。OS全体の最前面を占有しません。
- 測定登録の「同定済み試料から追加」を削除。ファイル名先頭の数字を通し番号へ取り込みます。`0015_sample.txt` は `0015` です。数字が先頭にない場合は手入力できます。
- 新しいピーク検出は、平滑化後の候補近傍にある実測点の最大位置へ登録します。既存の手動ピーク・同定済みピークを勝手に動かしません。表示専用マーカーも測定曲線上の強度に合わせます。
- 測定ピークの一覧・黒点を選ぶと、そのピークを中心に拡大します。初期値は±5°、左側で変更できます。Igor標準のCtrl+Iカーソルを使い、Ctrl+Aを独自のカーソル操作に割り当てません。
- 格子定数画面では参照棒を重ねず、同定結果の記号と測定曲線を表示。比較用グラフも残し、こちらも参照棒を表示しません。
- 参照TXTに明記された格子定数がある場合、計算値・標準誤差・参照値・差を並べます。参照値がない場合は「未収録」と表示し、推測で補いません。比較に用いた値は計算履歴に保存します。
- 共通の相・色・記号は、相を切り替えても同じウィンドウで編集します。凡例順には実際に同定で使った相だけを出します。
- 作図のプロジェクト一覧でホイールを使えます。展開・チェック後もスクロール位置を保持します。
- 同定途中のデータも作図できます。未完了データを含むときは作図前に確認し、同じ保存図の連続調整では確認を繰り返しません。
- Workbench内の重複する「プロジェクト一覧」ボタンを削除。上段のXRD Workbenchメニューから開けます。

## 参照格子定数のTXT形式

ヘッダーの例は `# lattice_a: 5.89`、`# lattice_c: 23.2` です。単位の基本はÅ。`# a_nm: 0.589` または値に `nm` を明記した場合はÅに換算します。`a / b / c`、`cell_a / cell_b / cell_c`、CIF由来の `_cell_length_a` 等も認識します。

既存の参照キャッシュに値がない場合、登録元TXTが見つかればヘッダーの明記値を読みます。PDFから格子定数を自動抽出する機能はありません。既存同定の参照indexを変えたり、元の参照カードを上書きしたりしません。

## 更新と配布

新規利用はZIP全体を展開し、同じフォルダ内の `xrd_main.ipf` をIgor Pro 9以降で開きます。Igor付属のPeak AutoFindが必要です。研究データ・利用者のExperimentはZIPに含めません。

既存Experimentは別名コピーと旧IPF一式を保持し、旧 `xrd_main.ipf` を閉じて新版へ切り替え、別名保存して再起動確認してください。IPFを単体で移動せず、一式の相対配置を維持します。

このPCへの適用結果・今回の検証結果は `TEST_RESULTS_v1.3.0.md` を参照してください。旧版はGitHubと一致した配布物だけを削除候補へ集約し、実験・元測定・参照データ・更新前バックアップは削除候補にしません。
