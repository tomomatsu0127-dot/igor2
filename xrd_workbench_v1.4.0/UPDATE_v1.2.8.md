# v1.2.8 更新案内

同定画面でピークや候補を選ぶ操作、比較グラフ更新、同じプロジェクト内でのタブ移動を軽量化しました。

一般利用者の操作や設定変更は必要ありません。これまでのプロジェクト順、測定の番号順、入力順（番号→組成→表示名）、5%のピーク検出初期値、比較の除外・順序・表示設定を引き続き使えます。

更新は49本体IPFを含むフォルダ一式を使用し、xrd_main.ipfだけを読み込みます。旧版と新版を同時にコンパイルしないでください。研究データを公開したり、元測定・参照ファイルを移動する必要はありません。新しい独立フォルダへ配置し、Experimentは別名で保存して再起動・再読込を確認してください。

Desktop QSに適用した場合、QS_update_v1.2.8_日時内のxrd_workbench_v1.2.8が外部Procedureの参照先です。その更新フォルダを残してください。更新前のPXPと旧IPF一式も同じフォルダへ保持しています。

旧版コードの画面を閉じた後は、その完了を待ってからentrypointを差し替えます。今回の専用検証Igorで画面終了とCloseProcを一緒に予約した際に1回native終了があり、別々に実行した再試行では正常でした。これは観察であり、Igor内部の原因が確定したという意味ではありません。

性能値と確認範囲は[検証結果](TEST_RESULTS_v1.2.8.md)を参照してください。600件を保管し5件を比較する条件の測定です。長時間連続使用、600件全曲線の同時描画、別PCと全DPI/モニター構成は未確認です。
