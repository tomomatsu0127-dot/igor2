# MH VSM Analyzer v2.1.2

Igor Pro 9用のMH作図拡張です。既存のv2.01を元に、凡例・縦横比・フォントを改良しました。

## v2.1.2の初期書式

右側の見本のような図を、比較グラフを作成した時点で出すようにしました。

- 初期の描画枠は12×9 cm（4:3）、英数字はTimes New Roman 24 pt。
- 凡例の日本語はインストール済みの明朝体（ＭＳ 明朝など）。英数字・記号はTimes New Romanを保ちます。
- 凡例は上部に2列。初期の曲線幅は2.5 pt。
- 軸は0を中心とした切りのよい範囲。今回の1100℃・N₂の4件なら横軸−15～15・5刻み、縦軸−40～40・20刻み、小数0桁、小目盛りなし。
- 値の大きい測定では、軸範囲も広げます。常に±40に固定して大きい磁化を隠す処理ではありません。
- 測定端の微小なオーバーシュートは、主目盛り間隔の0.05%以内なら表示範囲だけ名目値へ丸めます。例：15.0016 kOeに対し表示端は15 kOe。元のWave・VSMは丸めたり削除したりしません。

[新しい初期書式で出した実測図](previews/mh_1100_n2_reference_default.png)

### 既存の図も右の書式へ戻す場合

そのMHグラフをクリックして選択してから、操作パネルの**見本の書式にする**、またはMH解析メニューの**見本の書式を現在の図に適用**を選びます。

この操作は、寸法・文字・凡例・線幅・軸を見本の設定にします。凡例は一覧の名前から作り直すため、凡例だけを手動編集した場合は、先に一覧側の表示名へ反映してください。測定データと線の色は変えません。

保存済みの文字サイズ・線幅・寸法は、新版を読み込んだだけでは上書きしません。以前の図設定が残っていて見本と異なる場合も、このボタンで見本へ戻せます。適用後は次に作る図にもその書式を使います。

### v2.1.1からの入替

実験を別名保存してから、Igorのコマンド欄で旧版を外します。

```igorpro
CloseProc /NAME="MH_VSM_Analyzer_v2_1_1.ipf" /D=0
```

次に `MH_VSM_Analyzer_v2_1_2.ipf` を開いてください。新旧を同時に読み込みません。

## 導入：読み込むのは1ファイル

1. ZIPを展開して、分かりやすい場所に保存します。
2. Igorで **File → Open File → Procedure Window** を選び、**`MH_VSM_Analyzer_v2_1_2.ipf`** を開きます。
3. Compileが押せる場合は押します。エラーがなく、灰色ならコンパイル済みです。
4. 上部の **MH解析 → 操作パネルを開く** を選びます。

`src`内のファイルは開かないでください。同じ関数が重複します。XRD拡張とは別の`root:MHApp`を使用します。

### 旧MH版をすでに開いている場合

まず実験を別名の`.pxp`に保存してバックアップします。旧版と新版を同時に読み込まず、旧版の外部Procedureを外してから新版を開きます。

旧ファイルが指定の`MH_VSM_Analyzer.ipf`という名前なら、Igorのコマンド入力欄で次を実行できます。

```igorpro
CloseProc /NAME="MH_VSM_Analyzer.ipf" /D=0
```

これはProcedureを外し、元のファイルは残します。次に新版の1ファイルを開いてください。旧版と同じWave構造を使うので、既存の読込済み測定データも利用できます。操作パネルを開き直すと新しい配置になります。

### v2.1.0からの入替

今開いている旧版が `MH_VSM_Analyzer_v2_1_0.ipf` の場合は、実験を保存した後に、Igorのコマンド入力欄で次を実行します。

```igorpro
CloseProc /NAME="MH_VSM_Analyzer_v2_1_0.ipf" /D=0
```

その後、新しい `MH_VSM_Analyzer_v2_1_2.ipf` を開きます。新旧を同時に開かないでください。測定データと既存グラフはそのまま使えます。

## 軸・目盛り・小数桁数（v2.1.2で更新）

**MH解析 → 軸・目盛り・桁数を調整**、または操作パネルの同名ボタンを押します。図を選び、左右それぞれで最小値・最大値・主目盛り間隔・小目盛り数・小数桁数を設定します。

- **小数点以下「0桁」**：`15.00`を`15`にします。
- **「自動」**：5刻みは整数、0.5刻みは小数1桁、0.25刻みは2桁を選びます。
- **両軸を整数表示にする**：横軸と縦軸をまとめて0桁に設定します。
- **数字の重なりを避ける目盛り間隔を提案**：図の幅・文字サイズ・小数桁数から間隔を選びます。最小値・最大値は変えません。
- **図へ反映**：入力を図に適用します。設定画面は閉じないので、繰り返し調整できます。
- 小目盛り数の0は非表示です。

画像の例に近い設定は、横軸−15～15・間隔5・0桁、縦軸−30～30・間隔10・0桁です。範囲−30～30で間隔20にすると、ラベルは−20・0・20になります。

2桁などの長い数字も選べます。縦軸ラベルや端の数字が重ならないように余白を追加します。描画枠モードは枠の形を保持し、図全体モードは図全体の比率を保持します。凡例の手動編集は変えません。

[新しい軸設定画面](previews/mh_axes_settings.png) ／ [整数表示の例](previews/mh_axis_integers.png)

## 基本操作

1. **VSMを追加**：複数ファイルを選択できます。
2. 比較に入れる測定データをチェックします。名前の欄をダブルクリックして、`1200°C`、`x = 0.2`などに変更します。
3. **チェック分を比較**で比較図を作成します。1件なら**選択行を単独表示**も使えます。
4. **軸・目盛り・桁数**で範囲を整えます。例：横軸−15～15 kOe、主目盛り5 kOe。縦軸−80～80 emu/g、主目盛り40 emu/g。小目盛りを消す場合は0です。
5. **図のサイズ・凡例・フォント**で最終的な寸法を決めます。

磁場はOe÷1000でkOeへ、磁化はM(emu)÷試料質量(g)でemu/gへ換算します。元の`H_Oe`・`M_emu`と換算後のWaveを分けて保持します。質量がない・0以下の場合は読み込みません。

## 縦横比の2つの指定方法

比率はどちらも **横÷縦** です。`1.3333333333`なら4:3、`1`なら正方形です。

| モード | 幅・縦横比が表す範囲 | 凡例が増えた場合 |
|---|---|---|
| 描画枠 | 軸で囲まれた、曲線を描く長方形 | 枠の寸法を保ち、上の余白を増やす |
| 図全体 | 凡例・目盛り・軸ラベルを含む白いキャンバス。ウィンドウ枠やタイトルバーは除く | 図全体の寸法を保ち、残りの空間から描画枠の高さを計算 |

両方の比率を同時に固定する設定ではありません。見本のように**曲線部分の形を保って凡例だけ外へ広げる場合は「描画枠」**を選びます。

初期値はVSM資料に合わせて**描画枠12×9 cm、Times New Roman 24 pt**です。凡例は2列で、一覧の順番に「1・2／3・4／5・6」と配置します。列数は1～3列、文字は12～48 ptで指定できます。

凡例が長い場合、描画枠モードでは横の余白も追加します。図全体モードで文字が収まらない場合は、幅や列数を変更してください。入力が収まらない設定では対象の図を変更しません。次に作る図に保存設定が収まらない場合は、12×9 cmの描画枠に戻して作成し、履歴に通知します。

## 完成後もIgorで編集できます

- 凡例・軸・曲線をダブルクリックすると、Igor標準の編集画面が開きます。
- 凡例は列ごとのAnnotationです。文字、位置、色、線幅などを変更できます。
- `Cu\B2\MO`のようなIgorの下付き文字も、一覧の表示名や凡例に使えます。
- 拡張の**対象の図に設定を反映**を押すと、この拡張の凡例を一覧の名前から再配置します。手動で編集した凡例は置き換わります。追加した独自のTextBoxは残ります。
- レイアウトを反映しても、軸の拡大範囲と測定Waveは変えません。
- **書式を変えず画面に収める**は画面上の表示倍率のみ変更します。出力寸法と文字のポイント数を保ちます。

新規実験の初期の線幅は2.5 ptです。既に保存されている線幅は維持します。

色は見本に合わせ、比較図では赤・黄緑系・緑・青・桃・紫の順です。曲線をダブルクリックして自由に変更できます。単独表示は従来どおり黒です。

## 保存・出力

**File → Save Experiment**で`.pxp`に保存します。読込済みWave、試料質量、名前、図の設定を含みます。原本VSMを保存場所から移しても、保存済みWaveの作図はできます。

画像やPDFなどは、完成図を選択しIgor標準のグラフ出力を使います。画面キャプチャではなく、Igorのグラフ出力で保存すると、設定した寸法で出力できます。

## ファイル構成

- `MH_VSM_Analyzer_v2_1_2.ipf`：導入する完成ファイル。これだけで動きます。
- `src/MH_VSM_Analyzer.ipf`：読込・一覧・作図の開発用ソース。
- `src/mh_figure.ipf`：図のサイズ計算、凡例、設定画面、ガイド。
- `src/mh_axis.ipf`：軸範囲、主／小目盛り、小数桁数、間隔提案、ラベル用余白。
- `tools/build.py`：開発用ソースを導入用の1ファイルにまとめます。
- `tests/`：Igor実機テストと読込用の小さな人工データ。
- `TEST_RESULTS.md`：確認結果と未確認点。

実測の新しい作図例はMH-029、030、034、035の4件です。名前だけを一覧に設定し、軸・目盛り・フォントは新規作図時の初期設定で出力しました。

今回の範囲はMHの読込・単独／比較作図と書式です。HTML版のすべての解析機能を移植した版ではありません。新しいMs・Hcの計算、背景差引き、平滑化などは追加していません。
