# XRD Workbench v1.2.6

比較に追加した試料の除外・並べ替えと、既存の登録Wave名を使う比較表示を追加しました。

入口は **xrd_main.ipf** のみです。本体48 IPFを同じフォルダ構成で保持してください。

- 同定画面の「比較の追加・除外…」を開きます。左で試料を追加し、右の一覧で「選択した試料を除外」「すべて除外」「上へ移動」「下へ移動」を使えます。
- 試料間の間隔、参照線、同定マーク、未同定ピークを設定し、「比較図に反映」で確定します。キャンセルと×は変更を確定しません。除外しても測定データは残り、再追加できます。
- 比較の測定線は既存の int_norm / tt 登録Waveを直接参照します。縦のずらしはグラフのOffsetで行います。登録のない試料は元のProcessed / Raw Waveを参照します。
- 同定マークは相名と試料名に `_identified_R番号`、参照線は `_reference_R番号`、未同定ピークは `_unassigned` を付けた表示専用Waveです。同定マークは測定ピークを示し、参照線とは区別します。
- 既存の登録Wave名自体は変更しません。トレース名では小数点などをIgorの標準名へ変換し、化学式の下付き数字は通常の数字にします。Full Pathには登録済みのWave名が表示されます。長い名前は表示側だけを省略し、衝突時は番号を付けます。
- v1.2.5のプロジェクト管理・検出ピークのスクロール選択修正も含みます。
- 解析処理と保存schemaは変更していません。旧版とExperimentを保管し、コピーで切り替えてから保存してください。
