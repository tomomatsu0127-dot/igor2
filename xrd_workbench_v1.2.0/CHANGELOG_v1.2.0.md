# 変更履歴 v1.2.0 / 2026-10-27 JST

- 毎回のDoWindow/K→初期サイズNewPanel→復元を廃止。親フレームと同一画面のグラフを再利用。
- 同定段階の縦軸を−30〜110へ固定し、表示基準を同期。固定処理でUndoを消費しない。
- 参照の強度上位2反射を登録ピークと照合し、不足を表示・採用前確認。
- 小さい操作プルダウンを通常ボタンとネイティブメニューへ変更。
- 左比較の選択をプロジェクトごとに保存。編集中試料の強制追加を廃止。0件のときは空表示、再選択で復帰。
- 相・試料の凡例フォントを統一し、マウス操作の文字サイズスライダーを追加。
- 多列の凡例を単一のネイティブ注釈へまとめ、下付き解除後も共通サイズを保つ。
- 同定済み試料を他プロジェクトへコピー。新しい測定UIDと複製元情報を付与、元を保持。途中失敗時の復元を追加。
- 表示名を組成より先に配置し、一方向連動。変更していない表示名へ戻っただけでは編集済み組成を上書きしない。
- 初心者用・更新用マニュアルを更新。新しい保存schemaへの移行は行わない。
