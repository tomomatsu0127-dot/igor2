# XRD Workbench v1.1.0

ローカルv1.0.0を基に、通し番号による管理、UI整理、比較と作図を更新したIgor Pro 9以上向けの版です。

## 導入

1. 現在のExperimentを別名の.pxpに保存します。
2. ZIPを新しいフォルダへ展開します。
3. 旧版Procedureを閉じ、新版の **xrd_main.ipfだけ** を開きます。同時に別の版を読み込まないでください。
4. F6で解析画面、XRD Workbenchメニューからプロジェクト一覧を開きます。

## 主な変更

- Data1・Data2に代わり、手入力の015などを一覧・切替・比較に表示。先頭の0を保持。
- 登録時に測定フォルダも通し番号へ変更。同一プロジェクト内の番号重複は拒否し、別プロジェクトでは同じ番号を使用可能。
- 番号・組成・表示名を1画面で入力。引用符不要。新規Wave名は単一のアンダースコア。
- プロジェクト名で展開・折りたたみ。ダブルクリックで開く。
- Ctrl+Iの標準Aから追加。登録済みピークをカーソル移動で変更しない。
- 同定時の登録ピーク選択による自動拡大、段階1〜3の全体表示は維持。独自のダブルクリック・右クリック拡大を廃止。
- 他プロジェクトの同定済み試料を左の比較へ追加。
- Workbenchは4段階へ整理。作図・保存設定をそれぞれ上部メニューへ集約。
- 凡例1〜4列、別ウィンドウ・PNG出力。凡例でプロット部分を縮めない。

int_normのnormは「規格化」を意味します。元の強度はint_、0〜100の表示用強度はint_norm_に分離します。

既存の番号フォルダへの移行は、プロジェクト一覧の「選択試料の通し番号・組成」で内容を確認し再登録します。番号未入力の旧試料を勝手に自動採番しません。管理操作には事前バックアップと復元処理があります。
