# XRD Workbench v1.2.0

v1.1.0を基に、操作のたびに画面が縮小する問題、同定中の縦軸、比較図と凡例、試料登録を改善しました。対象はIgor Pro 9、実行確認はWindows版9.05です。

## 今の版から更新する

1. 現在のExperimentを **別名の.pxp** へ保存し、旧版IPFも残します。
2. 新版ZIPを新しいフォルダへ展開します。IPF一式を同じフォルダに保ちます。
3. Workbench・入力画面を閉じ、旧版xrd_main.ipfをExperimentから外します。新版の **xrd_main.ipfだけ** をProcedure Windowとして開きます。二つの版を同時に読み込まないでください。
4. F6でv1.2.0と既存の測定・同定結果を確認し、更新後も別名保存して開き直します。

測定・参照を読み込み直す必要はありません。具体的なメニューとコマンドは [更新ガイド](MANUAL_UPDATE_ja.html#update) にあります。IPFを採用済みのExperimentや独自Procedureがある場合の切替は未確認です。

## 今回の変更

- 親ウィンドウを維持し、同じ測定・段階ではグラフを再利用して更新します。
- 同定中は規格化強度の縦軸を−30〜110に固定。ピーク選択は横軸だけ移動します。
- 主・第2参照ピークに対応する登録測定ピークがない場合、採用前に確認します。範囲外は除外し、他相と重なる登録ピークも一致として扱います。採用は続けられます。
- 「その他の操作…」を読みやすいボタンに変更しました。
- 左比較にはチェックした試料だけを表示。選択と凡例の文字サイズはプロジェクトごとに保存します。「凡例」スライダーをマウスで動かして調整できます。
- 多列の凡例を1つのIgor注釈へ統合。完成図でもまとめて編集できます。
- 他プロジェクトの解析完了済み試料を、元を残して独立コピーできます。
- 登録欄を通し番号→表示名→組成へ変更。表示名から組成へのみ自動入力します。015など先頭の0は保持します。

既存の測定値・参照値・同定・格子計算・Undo/Redoは維持します。`int_norm`は元値と別に保存する0〜100の規格化強度です。旧図の手編集は自動で置き換えません。新しい単一凡例にする場合は作図設定から図を再作成します。
