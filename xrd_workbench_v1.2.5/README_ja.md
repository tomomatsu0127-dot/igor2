# XRD Workbench v1.2.4

プロジェクト追加・参照追加確認時に操作不能に見える問題の修正版です。

確認/入力の間だけ補助パネルを一時的に隠して、ダイアログを操作できるようにします。終了後に同じパネルを元の位置・サイズで戻します。管理画面が重複して残る問題も修正しました。

入口は **xrd_main.ipf** のみ。本体46 IPFを一式で保持してください。

旧版一式と現在のExperimentを保持し、旧版の画面・Procedureを外して新版の入口へ切り替え、F6で開きます。旧新版を同時に読み込まず、更新後は別名保存してください。測定・参照の再取込は不要です。
