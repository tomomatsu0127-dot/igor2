# MH VSM Analyzer v2.2.0

Igor Pro 9用。v2.1.2の完成済み作図書式を維持し、測定データと作成したMHグラフをExperiment内で整理する機能を追加しました。

## 導入・旧版からの切替

1. 使用中のExperimentを、元と別の名前の`.pxp`へ保存します。
2. 旧MHのProcedureを外します。v2.1.2ならIgorのコマンド欄で次を実行します。

   ```igorpro
   CloseProc /NAME="MH_VSM_Analyzer_v2_1_2.ipf" /D=0
   ```

3. File → Open File → Procedure Windowから **`MH_VSM_Analyzer_v2_2_0.ipf`** を開きます。
4. **MH解析 → データ・グラフ管理を開く** を選びます。

導入するIPFは1ファイルです。`src`や`tests`のファイルを併せて開く必要はありません。新旧のMH版を同時に読み込みません。旧IPFと旧Experimentは残してください。

## フォルダへ整理する

- ツリーのフォルダを選び、**フォルダを作成**で子フォルダを作ります。階層の深さは自由です。
- **このフォルダにVSMを追加**で、選択した場所へ複数の測定を読み込めます。同じExperimentへ後から追加できます。
- 測定・フォルダ・グラフを選び、**名前を変更**または**移動先を選ぶ**で整理します。
- フォルダのダブルクリックで開閉します。左のチェックは測定を比較図へ含めるためのものです。
- **チェックした測定で比較図を作成**で、所属フォルダが違う測定も比較できます。

この階層は拡張の管理ツリーです。内部のWaveの所在を固定しているため、名前変更・移動でも既存図との関連が維持されます。整理にはこの管理画面を使ってください。Windows上の原本VSMや、Igor標準Data Browserの物理フォルダを移動する操作とは別です。

## 作成したグラフを残す・開く

新しく作ったMH図は自動で台帳へ登録されます。図をツリーから開くと、使用した測定も右側に表示されます。測定を選ぶと、その測定を使用する図の一覧が表示されます。

- 図をダブルクリック、または**選択した測定・図を開く**で再表示できます。
- 開いている図を選んだ場合は、その現在の窓を前面に出します。
- **選択した図を閉じる**で窓を閉じても、管理ツリーから図は消えません。
- Igor標準操作で変更した凡例、軸、文字、曲線、TextBox、描画オブジェクトも保存対象です。
- **図の状態を記録**は、開いているMH図の編集状態を管理台帳へ記録します。その後、Experiment自体を保存してください。

再表示時に初期書式を適用し直しません。測定名の変更も、既存図の手編集済み凡例を勝手に書き換えません。新しく作る図には新しい測定名を使います。

## 保存して開き直す

**File → Save Experiment**で`.pxp`へ保存します。階層、測定との関連、図の編集状態、開閉状態をExperiment内へ保存します。保存直前に開いている図の状態も記録します。

閉じた図の再表示には、必要なWaveとこの版のProcedureが必要です。元VSMの再読込は不要です。IPFは別ファイルの依存として残る場合があるため、Experimentと対応するこのIPFを一緒に保管してください。

旧版の読込済み測定は、最初は「測定・グラフ」の下に並びます。開いている旧MH図も、見た目を変えずに登録します。旧版で既に閉じられ、再構築情報も残っていない図を後から復元する機能ではありません。

## 矢印は任意の補助機能

初期状態では**補助機能：矢印の位置調整**はオフです。データとグラフの管理に矢印機能は必要ありません。

必要なときだけチェックを入れ、対象の図を選んで**矢印の調整画面を開く**を押します。新しい矢印の追加、またはこの補助機能で追加した矢印の始点・終点を、kOeとemu/gの数値で調整できます。入力画面で取消を押すと変更しません。

Igor標準の描画ツールで作った既存矢印も図全体の保存・復元対象です。これらの位置は従来どおりIgorの描画ツールで編集できます。既存の複合図形やTagを、数値編集用の矢印へ自動変換しません。

## 維持した作図仕様

新規図の初期値は描画枠12×9 cm、英数字Times New Roman 24 pt、日本語凡例は明朝体、上部2列凡例、線幅2.5 pt。既存の配色、単独図の黒、軸・小数桁・余白・物理寸法の計算を維持しました。保存済みの独自書式は、その現在値を保持します。

従来の操作パネル、軸・目盛り・桁数、図のサイズ・凡例・フォントも引き続き利用できます。「見本の書式にする」など明示的な書式適用では、従来どおり凡例を再配置します。

Ms・Hcの計算、背景差引き、平滑化などの新しい解析は追加していません。Oe→kOe、emu→emu/g、原値Waveの保持は従来どおりです。

## 同梱物

- `MH_VSM_Analyzer_v2_2_0.ipf`：導入用の完成1ファイル。
- `src/`、`tools/build.py`：開発用ソースと組立処理。
- `tests/`：人工データ、試験コード、検証結果。
- `previews/`：管理画面と人工データの図。
- `TEST_RESULTS.md`：確認した内容と確認範囲。
- `SHA256SUMS.txt`：配布ファイルのハッシュ。

実測の原本や利用者のExperimentは含みません。
