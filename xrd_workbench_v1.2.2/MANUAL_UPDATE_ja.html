v1.1.0からv1.2.0への更新

今のExperimentの測定データや参照値を、読み込み直す必要はありません。ソフトのProcedureを新版へ切り替えます。

  1. IgorのFile → Save Experiment Asで、現在のExperimentを別名の.pxpへ保存します。旧版のIPF一式も残します。
  2. 新版ZIPを新しい別フォルダへ展開します。xrd_main.ipfだけを取り出さず、IPF一式を同じフォルダに保ってください。
  3. Workbenchと入力・設定ダイアログを閉じます。グラフやパネルを閉じても、Experiment内の測定データは削除されません。
  4. 旧版のxrd_main.ipfをExperimentから外します。直接開いた版なら、そのProcedureを閉じます。分かりにくい場合は、Igorのコマンド入力欄へ次を1行入力します。
    CloseProc /NAME="xrd_main.ipf" /COMP=0 /D=0

    /D=0は元のIPFファイルを削除しない指定です。関数の中へ貼るのではなくコマンド欄で実行します。

  5. File → Open File → Procedure Windowから、新版フォルダのxrd_main.ipfだけを開きます。必要な子IPFは自動で読み込まれます。
  6. F6で開き、タイトルがv1.2.0であること、プロジェクト・通し番号・同定結果が残っていることを確認します。
  7. 更新後も別名の.pxpへ保存し、一度閉じて開き直します。以後は更新後の.pxpとv1.2.0のフォルダをセットで保管してください。

同名の関数が重複するエラーが出た場合は、旧版と新版のProcedureが同時に残っていないか確認してください。旧版IPFを削除して解決しようとする必要はありません。採用済みProcedureや独自ProcedureがあるExperimentでは、この一般的な切替手順だけで完了できるかは未確認です。

今回変わったところ

項目v1.2.0
毎回小さくなって戻る画面親ウィンドウを保ち、同じ画面ではグラフも再利用して更新します。
主・第2参照ピークの不足範囲内の登録ピークとの不一致をグラフ下に表示。初回の採用時に「この参照で大丈夫ですか？」と確認します。範囲外は対象外。他相への割当位置と重なれば一致です。配向や未登録も考えられるので、採用は続けられます。
その他の操作小さいプルダウンを、画面サイズに応じた読みやすいボタンへ変更しました。
同定中の縦軸規格化強度−30〜110へ固定。ピークを変えたときに横の範囲だけを移します。
左比較の凡例相名と試料名は同じ文字サイズ。「凡例」のスライダーをマウスで動かしてまとめて拡縮できます。
比較する試料チェックした試料だけを表示します。初期状態は現在のプロジェクト全試料、選択した後は編集試料も強制追加しません。選択はプロジェクトごとに保存します。
複数列の凡例1つのネイティブ注釈へまとめます。図の凡例をダブルクリックして一緒に編集できます。
登録時の入力通し番号→表示名→組成の順。表示名を確定すると組成へ同じ文字を入れます。組成を編集しても表示名は変わりません。表示名を変えずにフォーカスを戻しただけでは、編集済み組成を上書きしません。

既に保存した図の手編集は勝手に置き換えません。旧版の複数注釈の凡例を1つに変える場合は、作図画面で列数などを指定して図を再作成してください。

他プロジェクトの同定済み試料を追加する

  1. 追加先のプロジェクトを開き、「測定データを追加」を押します。
  2. 他プロジェクトの同定済み試料から追加…を押します。
  3. 一覧の試料をダブルクリックし、番号・表示名・組成を確認して登録します。

元の試料は残し、測定値・ピーク・同定・格子計算結果と履歴を複製します。複製先は独立した新しい内部IDになります。元から複製先、複製先から元への自動同期はしません。元プロジェクトの解析Undo履歴はコピーせず、追加操作は管理用バックアップで復旧します。同じプロジェクト内の通し番号は重複できないため、必要なら登録前に変更してください。

左で比較したいだけの場合は、複製せず「比較する試料を追加…」から他プロジェクトの試料にチェックするだけで使えます。
