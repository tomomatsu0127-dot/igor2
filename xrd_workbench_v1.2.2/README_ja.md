# XRD Workbench v1.2.1

指定フォルダの `xrd_workbench_v1.2.0` を基に、測定ピーク・参照候補・ピーク同定・格子定数の画面切り替え時に、内容が一度小さく表示されてから拡大される問題を修正しました。

画面部品を作成中の強制描画を止め、現在のウィンドウサイズへ配置してから描画します。解析アルゴリズム、保存形式、元測定値、同定データの構造は変更していません。

## 更新

1. 現在のExperimentを別名の `.pxp` へ保存し、旧版のIPF一式も保持します。
2. 新版を別フォルダへ展開し、旧Workbench画面を閉じます。旧版の `xrd_main.ipf` を外し、新版の **`xrd_main.ipf` だけ** を開きます。相対includeを含むIPF一式は同じフォルダに保ち、旧新版を同時に読み込まないでください。
3. F6で開き、タイトルのv1.2.1と既存の測定・同定結果を確認します。更新後も別名保存します。

測定データや参照データの再取込は不要です。採用済みProcedureを含むExperimentでの更新は未確認です。
