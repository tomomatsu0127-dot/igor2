# XRD Workbench v1.4.0

「4 格子定数」と「作図」メニューに「格子定数の系列図…」を追加しました。

- 現在のプロジェクトの測定から選び、必要な場合は別プロジェクトの測定も追加できます。
- 相（参照カード）と晶系を選び、採用済みのピークを使って未計算・要再計算の測定をまとめて計算します。有効な既存結果は再利用し、新規の計算は各測定の履歴に追加します。
- 横軸は温度・組成・任意の数値から選び、行ごとに入力できます。組成の登録値を数値として読み取れた場合は初期値に使います。設定はプロジェクトごとに保存されます。
- 図は横軸の数値順に並べます。六方晶は左軸に *a*、右軸に *c*、立方晶は *a* を表示します。参照カードに明記された格子定数は点線で表示できます。同じ横軸値がある場合は各点を表示します。
- 保存図は作成時点の結果を保持します。測定と計算履歴のIDを記録し、対象の測定を完全削除した場合は関連する保存図も削除します。
