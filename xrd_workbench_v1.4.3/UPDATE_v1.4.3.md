# XRD Workbench v1.4.3

- 回折図の目盛りを外向きに変更。作図画面の「軸・文字・サイズを設定」で強度の下限と上限を調整できます。開いている回折図は右クリック、Workbench内は「作図 → Workbenchの強度軸を調整」で変更できます。
- 「Experiment設定 → グラフの初期値」で新規作図の幅・高さ、強度範囲と濃さを設定します。初期値は16×12 cm、−30〜140、40%。縦並びでは上限に試料間の間隔を加えます。濃さの設定は全プロジェクトの参照線にも反映します。
- 保存図の右クリックから「元データから今すぐ同期」または「元データとの自動同期を設定」を選べます。自動同期は図ごとに有効化できます。手動モードでは作成時または直近同期時の内容を表示します。IgorのWaveを直接編集した場合は手動同期を使います。
- 別試料の近い角度に別の同定があると、採用の前に確認します。角度の幅はプロジェクトの一致幅を使用します。比較図の試料表示は通し番号と組成などの短い表示名にし、凡例は図の上中央に配置します。
- 「共通参照ライブラリ」で参照カードを選び、「元の名前に戻す」から「変更を新しい版として保存」。以前の同定は当時の参照版を保持します。
- PNGの初期名は図に使った測定の所属プロジェクト名を使います。複数プロジェクトを含む図では最初に表示する試料の所属を使います。
- 同定画面の2θズームでは強度走査を省略しました。
