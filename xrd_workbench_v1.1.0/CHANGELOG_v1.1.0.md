# v1.1.0 / 2026-10-26

- 手入力の通し番号を一覧・切替・比較・作図の管理番号へ採用。新規登録時、実測定フォルダも015などへ変更。
- 先頭0を保持。同一プロジェクト内の番号重複を拒否。異なるプロジェクトの同じ番号は固定UIDで区別。
- 番号・組成・表示名の文字入力を1画面に集約。新規Wave名の区切りを単一_へ変更。
- プロジェクトを展開・折りたたみ、ダブルクリックで開く。作図対象の選択も同じツリーに集約。
- Ctrl+Iの標準カーソルAで追加。カーソル移動で既存ピークを移動しない。任意位置ダブルクリック・右クリック拡大を廃止。
- 同定のピーク選択時自動拡大、標準マルキー、段階1〜3の全体表示を維持。
- 他プロジェクトの同定済み試料を左比較へ選択追加。番号・試料名・相の記号を表示。
- Workbenchを4段階へ整理。作図とExperiment保存設定を上部メニューへ集約。
- 凡例の列数1〜4、独立凡例ウィンドウ、凡例PNG出力。プロット寸法を維持。
- リストの共通ホイール処理、周期表のサイズ追従、選択メニューの文字重なりを調整。
- 参照の欠損hkl・検出・照合・格子定数の式は維持。
