# v1.0.0 実装範囲 — 2026-10-26

ローカルv0.8.2を複製。ローカルでの実装をユーザーが明示承認。GitHubのIgor正本は前回調査で特定できず、今回はローカル版を基準にする。

## 原因・差分

現行改名はdisplayNameだけで、物理パスと生成Wave名を変えない。Registry、Undo target、userdata、文字列Wave、再作成文は物理改名だけでは追従しない。依存式はコンパイル済み参照が動いてもGetFormulaに旧名が残る。現行追従は全体表示から拡大せず、内部サブウィンドウに直接付けたhookも実イベントを受けない。

## 変更

- xrd_view100.ipf：親イベント分配、登録ピーク限定選択、Shift追加、自動拡大ON/OFF、段階ズーム、表示復帰、XY履歴。
- xrd_manage100.ipf：Management実フォルダ、固定UIDでの解決、実改名、変更計画、衝突検査、バックアップ、逆操作、復元可能な削除。
- xrd_register100.ipf：手動番号・独立組成、生成名のプレビュー・安全な別名、参照の閲覧用Wave。
- 既存のプロジェクト列挙、UI、Undo、保存、作図の接続箇所だけ変更。科学計算と元データは維持。v0.8.2のhkl欠損対応を保持。

## 保護

旧版、sources、参照原本、利用中のExperimentは変更しない。旧プロジェクトは明示操作でバックアップ後に移行する。検証は/Iによる独立Igorで行い、実行前バックアップ・故障注入・PXP再読込・同定・格子定数・作図の回帰を確認して配布する。
