# MH VSM Analyzer v2.5.0

**MH解析 → Experiment共通の図設定**を開きます。図を開く前でも設定できます。

- **図の大きさ**で、寸法の基準を「描画枠」か「図全体」から選び、幅と縦横比（横 ÷ 縦）を入力します。例えば正方形なら縦横比は `1` です。PNG全体の寸法を揃えたい場合は「図全体」を選びます。
- **凡例**は「上・線見本」「上・矢印」「右・矢印」から選べます。どの形式も凡例は一つのテキストボックスです。「上・線見本」は1〜3列を選べます。「上・矢印」は横一列で最大11項目です。多くの測定を並べるときは右の矢印または線見本が収まりやすくなります。
- **R.T. 枠**で表示の有無、文字サイズ、描画枠の右端・下端からの距離を指定します。距離はそれぞれ描画枠の幅・高さに対する割合です。初期位置は右下です。
- **Experiment全体に適用**を押すと、開いているMH図に反映され、以後の新規図・再表示する保存図にも適用されます。再開後も使うにはExperimentを保存します。

図中の `x = -0.1` などの数値の負号は、組版用の `−`（U+2212）で表示します。管理画面の表示名と元の.VSMのファイル名はそのまま使えます。

開いている図の軸範囲や独自の注記は共通設定の反映後も引き継ぎます。既存の保存図は、共通設定を初めて適用するまでは元の書式で開きます。設定した寸法に凡例が収まらない場合は、共通設定で幅・縦横比・凡例形式を調整してください。

Igor Pro 9で、旧版IPFを閉じてから `MH_VSM_Analyzer_v2_5_0.ipf` を開くと、別のExperimentにも導入できます。
