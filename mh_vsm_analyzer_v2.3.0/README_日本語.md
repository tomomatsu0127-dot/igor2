# MH VSM Analyzer v2.3.0

Igor Pro 9用。測定とMHグラフをExperiment内で整理し、試料番号・組成・元ファイル名を確認できます。従来の図の書式と保存済みの図の編集状態を維持します。

## 導入・旧版からの切替

1. 使用中のExperimentを、元と別の名前の `.pxp` に保存します。
2. 旧MHのProcedureを閉じます。v2.2.0の場合、Igorのコマンド欄で次を実行します。別の版の場合は、現在開いている旧IPFの名前に置き換えます。

   ```igorpro
   CloseProc /NAME="MH_VSM_Analyzer_v2_2_0.ipf" /D=0
   ```

3. File → Open File → Procedure Windowから **`MH_VSM_Analyzer_v2_3_0.ipf`** を開きます。
4. **MH解析 → データ・グラフ管理を開く** を選びます。

開くIPFはこの1ファイルです。新旧版を同時に読み込まないでください。旧IPFと元のExperimentは保管してください。

## .VSMを追加する

ツリーで行き先を選び、**このフォルダに .VSM を追加**を押します。ファイル選択の対象は `.VSM` で、複数選べます。追加直後の確認画面には、今回読み込めたファイルだけが表示されます。試料番号と表示名を別々に編集し、**反映して閉じる**で確定します。**今回追加分だけを別フォルダへ移動**で、今回の測定をまとめて整理できます。既に入っていた測定は対象外です。

| VSMファイル名 | 試料番号 | 表示名（新規図の凡例） |
| --- | --- | --- |
| `MH-044-x=0-1200inAir_26-11-07-18_33_52.VSM` | `044` | `x = 0` |
| `MH-017-x=0.2-1200inair_26-10-14-11_42_34.VSM` | `017` | `x = 0.2` |
| `MH-005-x=0.1,y=0.2-1200inAir_26-11-07-18_33_52.VSM` | `005` | `x = 0.1, y = 0.2` |

番号は文字列として保持するので先頭のゼロは消えません。同じ組成の測定も別々に登録できます。ファイル名がこの形式に当てはまらなければ、試料番号は空欄、表示名は拡張子を外したファイル名です。既存の測定には元ファイル名から番号を補い、既に付いている表示名や保存済みの図の凡例はそのまま残します。

## フォルダで整理し、比較する

- フォルダ行をダブルクリックすると子フォルダを開閉できます。**子フォルダを作成**、**名前・試料番号を編集**、**選択した項目を移動**で整理します。
- フォルダ行のチェック、または**フォルダ内を全チェック**で、そのフォルダ配下の測定をまとめて比較対象にできます。閉じている子フォルダも対象です。フォルダ行にはチェック済みの件数と全件数が表示されます。
- **フォルダ内を解除**は選んだ範囲だけ、**すべてのチェックを解除**はExperiment全体のチェックを外します。**チェックした測定で比較図を作成**で、別のフォルダの測定もまとめて作図できます。

これはExperiment内の管理ツリーです。整理にはこの画面を使ってください。測定やフォルダを移動しても、内部の測定データと図の関連は維持されます。PC上の原本VSMは移動しません。

## 図を保存・再表示する

新規MH図は管理ツリーに登録されます。図を選ぶと右側に使用した測定の試料番号と表示名が出ます。測定を選ぶと、その測定を使用する図が表示されます。

図のダブルクリック、または**選択した測定・図を開く**で再表示します。図を閉じても管理ツリーには残ります。軸、凡例、文字、線、テキスト、描画などを編集した状態で保存でき、再表示時に初期書式を適用し直しません。

**File → Save Experiment**で通常のExperimentを保存します。フォルダ、試料情報、図との関連、開いている図の最新の編集状態も保存されます。開き直す際に元VSMの読み直しは不要です。対応するIPFはExperimentと一緒に保管してください。

## 5分ごとの自動保存

管理画面を初めて開くと有効になり、Igorを開いている間、5分ごとに復旧用コピーを作成します。既定はIgorが認識するドキュメントフォルダの **MH_Autosave** です。最終保存時刻は管理画面に表示され、そこにマウスを置くと保存先が分かります。**自動保存先を選ぶ**で変更し、**今すぐ復旧用に保存**で手動でも作成できます。チェックを外すと停止します。

元の `.pxp` は上書きしません。作業中のExperimentごとに2世代の復旧用コピーを交互に更新します。復旧時は更新時刻の新しいコピーを開き、通常作業用に別名で保存してください。普段の保存は引き続き **File → Save Experiment** を使います。

## 図の書式と任意の矢印編集

既存の作図書式（12×9 cmの描画枠、英数字Times New Roman 24 pt、日本語の明朝体、上部2列凡例、線幅2.5 pt、軸・配色・余白）を維持しています。作図時の組成名には上のスペース整形が適用されます。

矢印の位置調整は初期状態でオフです。必要なときだけ**補助機能：矢印の位置調整を表示**をオンにし、対象図を選んで**矢印の調整画面を開く**を押します。この補助機能で追加した矢印は、始点と終点をkOeとemu/gで調整できます。Igor標準の描画ツールで作った矢印も従来どおり図と一緒に保存されます。

導入用IPFのほか、ソース、人工データの画面例、検証結果、配布ファイルのチェックサムを同梱しています。利用者のExperimentや実測データは含みません。
