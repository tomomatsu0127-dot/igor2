旧版v2.2.0で保存した検証用Experimentを、初期化前・初期化後・再起動後に比較しました。測定データなど31レコードの115フィールド群と、既存の管理フォルダ・測定ID・図の記録など9項目に差分はありません。既存の表示名は変更せず、元ファイル名から番号を補いました。保存図の再構成命令は管理用のID・フックを除いて一致しました。描画画像の黒と白の位置は一致し、旧版と新版で文字の輪郭の濃さに最大17/255の差がありました。新版の初期化後と再起動後の画像は画素まで一致しました。

## 性能

人工測定1,000件、10フォルダ。各測定に5点の数値Waveを2本用意し、同一PC・同じIgor環境で3回の計測の中央値を比較しました。値は処理時間で、マウス操作や画面への描画全体の応答時間ではありません。

| 操作 | v2.2.0 | v2.3.0 |
| --- | ---: | ---: |
| ツリーの全更新 | 16.37 ms | 3.56 ms |
| 測定1件のチェック変更 | 59.58 ms | 0.54 ms |

ツリーは必要な行を先に確保し、フォルダごとの順序でまとめて組み立てます。個別チェックでは対象行と親フォルダの件数だけを更新します。取り込みではまとめて表示を更新し、再構成命令が同じ開いている図の保存状態は作り直しません。管理フォルダのWave数は新しい保存項目・表示用の項目で8本から17本に増えましたが、繰り返し更新で増加しませんでした。
