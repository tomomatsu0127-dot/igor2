# XRD Workbench v1.2.7

測定の番号順、プロジェクトの並べ替え、登録画面と初期値の設定を改善しました。入口は **xrd_main.ipf** のみです。49本体IPFを同じ構成で保持してください。

- 上部の測定選択一覧とプロジェクトツリーは、通し番号の数値順です。000、001、002、010のように並びます。番号が未登録の測定は末尾に置きます。元の番号文字列、物理フォルダ、手動の作図積層順と比較の表示順は変えません。
- 「プロジェクト一覧」で対象を選び、「選択プロジェクトを上へ／下へ」で並べ替えます。順序は固定IDで保存するため、名前を変えても保持します。新規プロジェクトは末尾に加わります。
- 測定データの登録は「通し番号 → 組成 → 表示名」の順です。Tabで次へ進みます。組成を変更すると表示名にも反映し、必要なら表示名だけを変更できます。組成が同じまま再びフォーカスしても、手動の表示名は維持します。引用符は不要です。
- 登録成功で追加画面を閉じます。入力エラーやファイル選択の取消では、下書きと既存データを保持します。追加完了後は比較図の横軸も主図へ揃えます。
- ピークの最小突出量の初期値は **5%** です。「XRD Workbench → ピーク検出の初期値…」、または検出設定の下部から変更できます。新規測定と標準プリセットに使い、既存測定の条件は自動変更しません。初期値とプロジェクト順はExperimentを保存すると残ります。
- 新しいプロジェクト名は、引用符のない通常の入力欄で作成できます。空プロジェクトでは追加の案内を表示し、測定が必要なピーク操作を無効にします。
- 同定画面の「その他の操作…」へ「次／前の未同定ピークへ」を追加しました。末尾では先頭へ巡回し、Unknownのみのピークも対象にします。同定結果は変更しません。

前版の比較の除外・順序・表示設定、登録Wave名を使った比較、ピークのスクロール選択修正も含みます。保存済みの測定・参照・同定・作図スナップショットは保持します。
