# v1.1.0 修正範囲

基準はローカルv1.0.0。既存版・sources・原本・既存Experimentを変更しない。

- xrd_plot81/xrd_v80_ui：常時展開の表を、Project UIDで状態を保存する折りたたみ一覧に変更。
- xrd_import/xrd_register100：DoPromptの引用符付き段階入力を、通し番号・組成・表示名の文字欄1画面にする。採番せず015を保持。新規名の区切りは単一_。旧名は自動移行しない。
- xrd_ui/xrd_view100/xrd_v44：不要コントロールを除去、4工程、データ名から選択。独自クリック位置選択とダブル／右クリック拡大を廃止。登録ピーク選択時の拡大、Igor標準範囲操作・全体復帰、Ctrl+IのA位置の追加を維持。
- xrd_plotworkspace/xrd_v51：凡例の列数設定・独立凡例出力。凡例の余白確保でプロット領域を縮めない。
- 各リストの共通wheel処理、周期表の可変サイズ、比較図の試料名・相記号凡例。

解析式、元データ、hkl欠損、既存同定・保存・改名・削除の仕組みは再利用。ネイティブIgor別プロセスで検証する。

追加確定：通し番号を画面上の管理番号と実測定フォルダへ反映。同一Projectの番号重複を拒否、別Projectは許可。固定UIDは維持。旧DataNは明示した登録更新時に移行。番号変更は既存のバックアップ・操作記録・逆操作を利用し、依存式・保存図のつながりを検証。
