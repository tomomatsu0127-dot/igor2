# XRD Studio v0.2.0

Igorが担当していたデータ表・グラフ操作・保存・Undoなどを、独立したWindowsアプリに組み込んだ開発版です。XRD専用です。Igor、Python、Excelの別途インストールは不要です。

## 起動する

配布ZIPを展開し、`XRD_Studio_v0.2.0.exe`をダブルクリックします。単一EXEの初回起動では、同梱ライブラリの一時展開に時間がかかります。ネット接続・ログインは不要です。

最初は上部の「人工データで試す」を選んでください。人工データは実在物質の同定用ではありません。

## 基本の流れ

1. 左の「＋プロジェクト」で名前を登録します。
2. 「＋測定」でTXT/CSV/XY/DATの2列データを選び、通し番号・表示名・組成を入力します。015の先頭0を保持し、番号は自動採番しません。
3. 「1 測定ピーク」で条件を設定し「この条件でピークを検出」。手動追加は角度入力、またはグラフをクリックしてカーソル位置を確認してから追加します。外部ピークリストも追加できます。
4. 「2 参照候補」で参照ファイルを追加します。列名は2theta/I/h/k/l。dは任意。hkl不明は `-` または `none`。使用するカードへチェックします。
5. 「3 ピーク同定」でピークを選び、候補・参照パターン・証拠表を確認して採用します。既採用相/新しい相モード、重なり追加、Unknown、解除が使えます。
6. 必要なら局所フィットを行い、結果を見て中心を明示採用します。新しくフィットしただけでは採用済み中心を変更しません。
7. 「4 格子定数」で相、結晶系、波長、ゼロ補正、除外IDを指定して計算します。立方晶3反射以上、六方晶4反射以上。hkl不明は除外します。
8. 「保存」で `.labx` に保存します。元測定・規格化値・参照・同定・作業データ・フィット・格子履歴・完成図・Undo/Redoを含みます。

## Igorが担っていた機能の置き換え

|Igorの役割|この版の操作|
|---|---|
|Wave・データフォルダ|プロジェクト/試料ツリーとデータブラウザー。元値と規格化値は読取専用|
|Waveの表編集|「表示 → データブラウザー」で規格化値を独立した作業コピーへ。強度列を編集できる|
|単位・Note|作業データに名前・単位・注記を保存|
|基本的な数値処理|作業コピーへ倍率、定数加算、規格化、数値微分、平滑化。解析へ自動反映しない|
|Graph・カーソル|拡大/移動/戻る/全体表示、クリック位置の縦線と角度表示。通常クリックでピークを追加しない|
|軸と図の書式|図寸法cm、文字/線幅pt、凡例1-4列、軸範囲/軸ラベル、タイトル、注釈|
|図と表の出力|PDF/SVG/PNG、CSV、XLSX。Excel本体を起動せず出力|
|Undo/Redo|Ctrl+Z / Ctrl+Shift+Z。20操作の文書履歴を保存後も保持|
|Experiment保存|自己完結した `.labx`。元ファイルや参照フォルダを移動しても再開可能|
|自動保存・復旧|5分ごとに3世代の復旧コピー。次回起動時に候補を選択。通常保存の未保存表示は解除しない|
|パネル/補助画面|主画面を再生成せず、設定・データ表・フィットを独立した補助画面で操作|

作業コピーの表とグラフは同じデータから描きます。処理後の表・図を出力できます。原測定値を直接編集する機能は設けていません。

## プロジェクト管理・比較・完成図

左の試料名を選ぶと編集対象が切り替わります。チェックは比較対象の選択です。別プロジェクトの試料も比較でき、編集中の試料を自動で追加しません。

プロジェクトや試料を右クリックすると、名前/登録情報の変更、複製、ごみ箱への移動、復元を行えます。複製は別IDとなり元の試料から独立します。ごみ箱の内容は文書へ保持されます。

「比較・作図」のライブ比較は現在の解析値を表示します。「完成図として保存」はその時点の数値と図設定を固定します。後の解析で保存図を勝手に更新せず「元解析に変更あり」と表示します。左下で保存図を選び直せます。

図の出力は現在の表示範囲・参照候補を反映し、寸法と文字サイズは図設定を使用します。PNGは300/600dpiを選べます。フィット画面ではフィットと残差の図も出力できます。

## 保存と互換性

本版はschema 2で保存し、旧独立版v0.1.0のschema 1も読み込みます。旧文書を残して別名保存してください。schema 2を旧版で開くことはできません。アプリの版と保存schemaは別の番号です。

復旧コピーは `%LOCALAPPDATA%\XRDStudio\Recovery` に保存します。通常の作業の区切りでは上部の「保存」を使ってください。原子的保存により、書き込みが完了するまでは既存文書を置き換えません。

## 現段階の範囲と残り

本版は実装開始段階の実行可能な開発版です。現行Igor版の全機能移行・実測での同等性確認が終わった安定版ではありません。

- ピーク検出はSciPy方式です。Igorの旧方式/Robust方式/Peak AutoFindの完全移植・検出性能比較は残っています。
- type別カード専用管理、周期表UI、参照の科学的版更新、全確認一覧、試料順の自由並替えは未完了です。保護typeと元素集合による候補判定は実装しています。
- 個別の試料線/相マーカー書式、凡例だけの出力、注釈の自由配置、Igor並みの全グラフ編集は未完了です。現版の書式編集は図全体の主要項目です。
- 任意のIgor式・Procedure・SetFormula・コマンドの互換実行、汎用多次元Wave編集、PXP直接読込は実装していません。
- XLSXは解析表の出力に対応。XLSX入力・Excelからの逆同期は未実装です。解析状態の正本は.labxです。
- 検出と格子計算は画面を止めない処理へ分離。候補計算、局所フィット、大容量保存の非同期化と長時間/大量データの性能検証は残っています。現在のUndoは最大20個の状態を保持します。
- 実測、全DPI/複数モニター、別のクリーンPCは未確認です。Igor/PXPの互換性試験と、独立版.labxの保持試験は区別しています。

## 開発を続ける

設計は `docs/xrd_standalone_design_v1.0.0`、今回の対応は `IGOR_FOUNDATION_v0.2.0.md` と `FEATURE_PROGRESS_v0.2.0.md` を参照します。

ソースはPython 3.12と `requirements.txt` のライブラリを使い `python run_studio.py` で起動します。試験は `python -m unittest discover -s tests -v`、EXE作成は `python build_windows.py` です。利用者はEXEのみで起動できます。
