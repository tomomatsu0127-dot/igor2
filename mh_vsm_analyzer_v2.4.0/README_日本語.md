# MH VSM Analyzer v2.4.0

Igor Pro 9向け。**MH解析 → データ・グラフ管理を開く**から使います。導入するのは `MH_VSM_Analyzer_v2_4_0.ipf` の1ファイルです。別のExperimentへ入れる場合は、Experimentを別名で保存し、旧MHのIPFを閉じてから新しいIPFを開きます。

## 右クリックで整理

| 右クリックする行 | できる操作 |
| --- | --- |
| フォルダ | 名前変更、移動、同じ階層で上へ・下へ、削除 |
| 測定の表示名 | 名前・試料番号の変更、移動、同じフォルダ内で上へ・下へ、.VSMの差し替え、測定データの削除、元の.VSMファイルの削除 |
| 旧版で保存済みのグラフ | 開く、名前変更、移動、PNG保存、削除 |

フォルダを削除すると中身は親フォルダへ移ります。移動先に同名フォルダや同名の保存図があれば、名前を変えてから削除します。

データの差し替えは、新しい.VSMの測定値と出典を同じ行に入れます。設定済みの試料番号、表示名、所属先、グラフとの関連は引き継ぎます。

**測定データを削除**はExperiment内の測定と、その測定を使う保存図を消します。別のIgorグラフや表でデータを使用中なら、その窓を閉じてから再実行します。**元の .VSM ファイルを削除**では、確認に表示された原本をディスクから削除し、Experiment内に取り込んだデータは保持します。後者のディスク上の削除は元に戻せません。

## グラフを見る・画像で保存する

新規グラフは管理ツリーに保存図として追加されません。ウィンドウの×または**グラフを閉じる**ですぐ閉じます。管理画面が最大化されている場合は、その位置と大きさのまま手前にグラフが開きます。右クリックメニューの**画像を保存…**でPNGを書き出せます。初期ファイル名は測定の元ファイルと同じ名前で、比較図では先頭の測定の名前を使います。

旧版の保存図は引き続き管理ツリーに表示されます。行の右クリックにある**グラフを削除**で、保存図と開いている窓を取り除けます。新しい編集を保存する場合は画像として書き出します。

Igor Pro 9では、Experimentを保存する時点で開いているグラフ窓が、Igor標準の保存でExperimentに含まれることがあります。Experimentにも図を入れずに保存したい場合は、グラフ窓を閉じてから保存します。Igor Pro 10では新しく開くMHグラフはExperimentの保存対象から除外されます。

5分ごとの復旧用コピーは引き続き作成されます。矢印の位置編集は必要に応じてオンにします。
