# MH VSM Analyzer v2.4.0 検証結果

WindowsのIgor Pro 9.05で、作業用Experimentとは別のプロセスで検証しました。管理操作30項目、軸21項目、図と読み込み82項目、初期書式25項目、再起動後の再開2項目が合格しました。

- データを差し替えても試料番号、表示名、内部ID、所属フォルダを引き継ぎ、開いている図には新しい値が反映されました。
- フォルダ削除で中身を親へ移し、測定削除で元の.VSMを残せました。削除する測定を表示中のMHグラフだけを閉じ、Igorの別のグラフがデータを使用中なら削除を停止しました。原本削除は人工.VSMのコピーで確認しました。
- 最大化前後で管理画面の位置と寸法が一致しました。描画枠12×9 cm、軸、凡例、PNG出力を確認しました。既存保存図は通常表示と最大化画面で開け、開いている図を重ね表示に切り替えても編集内容が残りました。
- デスクトップExperimentのコピーから401件、1,766フィールド群を比較し、測定値、Waveの情報、試料番号、フォルダ、保存図に差分はありませんでした。更新後のExperimentのコピーは、インストール済みIPFを参照して別プロセスで開き直しました。
- マウスによる右クリックから保存ダイアログまでの通し操作と、Igor Pro 10は未検証です。右クリックの各処理とPNGの生成はIgor Pro 9.05で確認しました。

人工測定1,000件・10フォルダの同一構成で5回計測した中央値です。

| 操作 | v2.3.0 | v2.4.0 |
| --- | ---: | ---: |
| フォルダ内の一括チェック | 37.2 ms | 11.3 ms |
| 全チェック解除 | 27.5 ms | 7.2 ms |
| 単独図の作成 | 96.3 ms | 86.0 ms |

一括チェックはフォルダの所属判定をまとめ、全解除は一括でフラグを更新します。新規図の管理記録を毎回作る処理も外しました。計測値は処理時間で、画面描画全体の応答時間とは異なります。
