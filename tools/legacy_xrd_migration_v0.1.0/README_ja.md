# 手作業 XRD 実験の取り込み v0.1.0

Windows の Igor Pro 9.05 と XRD Workbench v1.4.4 用です。同梱の IPF を追加すると、旧 Experiment の測定曲線を Workbench に登録できます。

## 使い方

1. XRD Workbench を開き、取り込み先の Experiment とプロジェクトを選びます。試す場合は、取り込み先の Experiment を別名で保存してから作業します。
2. Igor の **File → Open File → Procedure…** から、`xrd_legacy_migration.ipf` を開きます。**XRD Workbench → 手作業の実験を取り込む (.pxp)…** を選び、元の `.pxp` を指定します。
3. **元の測定 Wave** で測定を選びます。候補に出ない場合は **2θ と強度の Wave を手動選択…** で指定します。2θ は度で、同じ点数の1次元数値 Wave を選びます。
4. 通し番号、組成、表示名を入力し、**この測定を登録** を押します。曲線だけ引き継ぐ場合は **照合できたピーク・相も登録** のチェックを外します。続けて別の測定を選べます。
5. 取り込み画面を閉じ、取り込み先の Experiment を保存します。登録した試料を選ぶと **XRD Workbench → 選択中の測定の移行記録…** から照合結果を確認できます。

## 引き継がれる内容

- 自動選択は、同じフォルダー内の `tt_番号…` と `int_番号…` を候補にします。手動選択では任意の Wave 名を使えます。いずれも元の数値を保持します。元の `.pxp` は読み取り専用で扱います。
- 自動選択では、`tt_相名_番号…` と `int_相名_番号…` のマーカーを照合します。同じ番号の測定の中で曲線上の点を一意に特定し、対応する参照反射の hkl も特定できた場合に、相同定として登録します。曲線上の点だけを特定できた場合は、未同定ピークとして扱います。曖昧な行は照合結果から確認できます。手動選択は測定曲線の登録に対応します。
- 既存の通し番号への上書きは行いません。同じ番号の別条件の測定を元の番号のまま移す場合は、登録先のプロジェクトを分けてください。
- 元のグラフの矢印、注記、書式、自由描画は元の `.pxp` に残ります。測定と同定結果の編集は Workbench で続けられます。

動作確認は Windows の Igor Pro 9.05 と XRD Workbench v1.4.4 で実施しました。Igor のデータ取り込み仕様は [WaveMetrics LoadData](https://docs.wavemetrics.com/igorpro/commands/loaddata) を参照してください。
