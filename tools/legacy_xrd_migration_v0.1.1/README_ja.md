# 手作業 XRD 実験の取り込み v0.1.1

Windows の Igor Pro 9.05 向けです。配布 ZIP には起動用 IPF と XRD Workbench v1.4.4 が入っています。

## 初めて使う

1. ZIP をフォルダーごと解凍します。
2. Igor の **File → New Experiment** で空の Experiment を作ります。すでに開いている XRD Workbench v1.4.4 に追加するときは、その画面から始められます。
3. **File → Open File → Procedure…** で、解凍フォルダー直下の `start_xrd_migration.ipf` を開きます。
4. 上部の **XRD移行 → 手作業の実験を取り込む (.pxp)…** を選び、移行元の `.pxp` を指定します。

旧版で Function Compilation Error が表示されている場合は **Quit Compile** を押し、手順2から始めます。移行元に保存確認が出たときは、旧版 IPF を開いただけなら保存せず閉じます。

## 測定を登録する

1. **元の測定 Wave** で試料を選びます。候補に出ない場合は **2θ と強度の Wave を手動選択…** から、同じ点数の1次元数値 Wave を選びます。2θ の単位は度です。
2. 通し番号、組成、表示名を入力し、**この測定を登録** を押します。測定曲線だけを移す場合は **照合できたピーク・相も登録** のチェックを外します。
3. 取り込み画面を閉じ、取り込み先を別名で保存します。登録済みの測定を選ぶと **XRD Workbench → 選択中の測定の移行記録…** で照合結果を確認できます。

自動選択では、同じフォルダーの `tt_番号…` と `int_番号…` を測定候補にします。`tt_相名_番号…` と `int_相名_番号…` のマーカーは、測定点と参照反射の hkl が一意に決まる場合に相同定として登録します。測定点だけを特定できた場合は未同定ピークとして登録します。曖昧な行は移行記録に残ります。手動選択は測定曲線の登録に対応します。

元の `.pxp` は読み取り専用で扱います。元のグラフの矢印・注記・書式は元ファイルから確認できます。通し番号は同じプロジェクトで重複できません。同じ番号の別条件の測定を移す場合はプロジェクトを分けます。
