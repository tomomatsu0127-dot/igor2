# XRD Wave 確認ツール v0.2.0

Windows 64-bit 用です。保存済みの Igor Packed Experiment（`.pxp`）から回折曲線を探して、確認した測定を XRD Workbench が読める2列のテキストとして書き出します。

## Wave の確認

1. ZIP を右クリックして **すべて展開** し、展開先の **XRD_Wave_Review.exe** を起動します。同梱の `_internal` フォルダも同じ場所に置きます。
2. **.pxp を開く…** で元の実験を選びます。Igor で編集した直後の実験を使う場合は、元の実験を別名で保存してから選びます。
3. 試料番号順の一覧で行を選び、2θ・強度の Wave 名と回折曲線を確認します。試料番号と焼成条件・工程は一覧の下で直せます。条件が分からなければ空欄のまま **この行を確認済みにする** を押せます。
4. 自動で候補に入らない測定は **Wave を手動で組む…** で、角度が度単位の2θ Wave と強度 Wave を指定します。
5. **確認済みを書き出す…** で保存先を選びます。選んだ場所の中に新規フォルダが作成されます。

出力フォルダの中は `試料番号／焼成条件・工程／測定.txt` の順です。条件が空欄の測定は **条件未記載** に入り、同じ試料・条件の繰り返し測定にはファイル名の連番が付きます。`review_manifest.csv` に元の2本の Wave と出力ファイルの対応を記録します。

## XRD Workbench v1.4.4 へ登録

Workbench の取り込み先を開き、**測定データを追加** から、書き出した各測定の `.txt` を選んで登録します。登録画面の通し番号、組成、表示名を確認してください。同じ試料番号の別条件を両方残す場合は、条件別のプロジェクトを選んでから登録すると、同じ通し番号を使えます。既存測定の差し替えを尋ねられた場合は、両方残すなら取り消します。

自動検出は同じ Igor Data Folder にある `tt_番号…` と `int_番号…` が対象です。試料番号と条件の候補は Wave 名と Data Folder 名から読み取ります。温度、雰囲気、保持時間や、`presinterd`（仮焼）、`milled`（粉砕）に対応します。曖昧な略称は Wave 名で確認できます。書き出すのは測定曲線と確認した分類です。元の `.pxp` にあるグラフ、注記、ピーク・相同定はそのファイルで参照できます。

## ソースから起動

Windows の PowerShell で、このフォルダを開いて実行します。Python 3.12 で確認しています。

```powershell
python -m pip install -r requirements.txt
python app.py
```

配布 ZIP には Python ランタイムと依存ライブラリが入っています。付属のライセンスと [igor2 のソース](https://github.com/AFM-analysis/igor2) を参照してください。配布版では `_internal/external/igor2` のソースを入れ替えられます。
