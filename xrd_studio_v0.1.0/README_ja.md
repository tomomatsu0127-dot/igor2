# XRD Studio v0.1.0

Igor Proを必要としないWindowsデスクトップ解析アプリの**開発プレビュー**です。旧XRD Workbench v1.2.0のコードを調査し、主要な解析操作を独立したPythonエンジンで新規実装しました。旧版の全機能を移植済みの完成版という意味ではありません。

## 起動

配布フォルダの `XRD_Studio_v0.1.0.exe` をダブルクリックします。PythonとIgorのインストールは不要です。初回は実行ファイル内のライブラリの展開に時間がかかります。ネット接続・ログインは不要です。

まず上部の「人工データで試す」を押し、解析条件の「この条件でピークを検出」を押してください。人工データは実在物質の同定用ではありません。

横長画面では左に測定一覧、中央にグラフと表、右に解析条件を表示します。狭い画面は上部の「解析グラフ」「プロジェクト・測定一覧」「解析条件」のタブで切り替えます。ピーク・候補の表にも切替タブがあります。

## 基本の流れ

1. 測定一覧で「測定ファイルを追加」。2θ (deg) と強度の2列を読み込みます。txt/csv/xy/dat、空白・タブ・カンマ・セミコロン区切りに対応。先頭の見出し・コメントは除き、数値行の欠損や列違い、重複・逆順の角度はエラーにします。
2. 「共通参照ライブラリ」から参照ファイルまたはフォルダを追加。必要な列名は `2theta I h k l`。順序は自由、追加列も使えます。hklが不明な場合は `-` または `none` と記載します。dは省略可能です。Iを構造因子や多重度から推定しません。
3. 「解析条件」で高さ・突出度・最小間隔・平滑化幅を指定してピーク検出。測定の生値は変えません。規格化は `100*(raw-min)/(max-min)`、定数データは0です。
4. 登録ピークを選び、「同定候補」で候補を確認。「選択した候補を同定に追加」で採用。主・第2参照反射に対応する登録ピークがなければ確認を表示します。重なった測定ピークへ複数の相を登録できます。
5. 未知ピークは「Unknownにする」。全ピーク確認後に「同定完了」。再検出では手動ピーク・確認済みピーク・割当済みピークを保持します。
6. 必要なら局所フィット、格子計算、比較図を作ります。図をダブルクリックすると手動ピークを追加。上部ツールで拡大・移動ができます。
7. 「保存」で `.labx` 文書として保存し、後日「開く」で再開します。

## フィット・格子計算

局所フィットはGaussianまたはLorentzian、両端3点の平均を結ぶ直線背景と定数項を使います。中心・不確かさ・FWHM・残差を保持。計算しただけではピーク中心を変えず、「フィット中心を採用」で変更します。再フィットでも既に採用した中心は勝手に変えません。

格子計算は同定済みの参照相を選択し、測定波長 (Å)・ゼロ補正 (deg)・除外ピークIDを指定します。立方晶は3本以上、六方晶は4本以上のhkl既知反射が必要です。旧IPFの変換式を用いる無重み最小二乗回帰を実装しました。ランク不足・物理的に不正な解は拒否します。入力・共分散・残差・参照revision・計算履歴を保存し、同定や採用中心が変わった履歴には再計算が必要な表示を付けます。

ピーク検出にはSciPyのSavitzky–Golayとfind_peaksを使います。Igor Peak AutoFindと同一のアルゴリズムではありません。アルゴリズム名とSciPy版・条件を文書へ保存します。

## 図と出力

測定一覧の□/☑で比較対象を選び、「チェックした試料を比較」。選択した試料だけを表示します。試料の表示名が凡例になります。図全体の幅・高さ (cm)、文字 (pt)、線幅、凡例列数、横軸範囲、縦ずらし、注釈を設定して「書式を保存して図に反映」を押します。

「図を出力」でPDF/SVG/PNG (300 dpi) を作成します。出力は保存済みの図設定を使います。ツールバーで一時的に拡大した範囲を出力に使う場合は、図の書式の横軸範囲にも設定してください。局所フィットの残差画面は本版の出力対象外です。

「結果CSV」で元値・規格化値、ピーク・割当・hkl、解析条件を新しい出力フォルダへ書き出します。格子履歴とフィットの完全な状態は.labxへ保存されます。

## 保存と復旧

.labxは元測定値・処理後値・参照反射・ID/revision・同定・フィット・格子履歴・図設定・Undo/Redo（20操作まで）を含みます。ZIP + JSON + NumPy配列で構成し、pickleや手続きコードを実行しません。配列はSHA-256で検証し、同じ配列は一つにまとめます。保存は一時ファイルの書き込み完了後に置換します。元ファイルの名前とハッシュを由来として保持し、元ファイルの絶対パスは必須にしません。

5分ごとに、このPCの `%LOCALAPPDATA%\LabStudio\Recovery` へ3世代の復旧コピーを保存します。復旧するときは「開く」から対象.labxを選択してください。復旧コピーは通常保存の未保存表示を解除しません。

## 開発の境界と残り

- 既存.pxpの読込、Igor手続きの実行、Wave式の互換実装はユーザーの指定により対象外。
- 現在はXRDを独立したアプリとして実装。MT/MHエンジンと画面は未実装。`studio/document.py` の共通文書形式とUIから独立した解析エンジンを将来の統合基盤とします。統合済みではありません。
- 旧v1.2.0にあるtype別カード運用・保護分類・専用の元素互換判定、外部ピークリスト読込、複数作図レシピの管理、試料の並べ替え/削除管理、候補モード別スコアと全証拠表、Igorの自由なグラフ編集との同等性は未実装または未確認です。現在の参照絞込みは名前/組成式/分類の部分文字列検索です。
- 研究室の実測値との解析結果の比較、全DPI/全モニター、大量データ、長時間運転、別のクリーンなWindows PCは未確認です。

## ソースから実行・ビルド

Python 3.12、requirements.txtの依存ライブラリで `python run_studio.py` を実行します。ビルドはPyInstaller 6.20.0を用い、`python build_windows.py`。試験は `python -m unittest discover -s tests -v`、GUI接続試験は `python -m tests.gui_smoke`。
