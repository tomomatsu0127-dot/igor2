2026-10-29 JST。設計のみ。本体コードと解析データへの変更はない。

- 基準: XRD Workbench v1.2.3 / codex/xrd-v1.2.3 / fb0c031093659db9db2562753dd0a0bd34561e4e。
- 対象: XRDのみ。ユーザーは一度示したM-H/M-T将来統合を撤回したため今回の設計に含めない。
- 52機能を45 IPF・604関数・14,632行のコードから整理。

- 設計書PDFは15ページ。編集可能なMarkdownと、根拠関数/行番号/ハッシュを持つJSONを同梱。
- 設計資料の207静的検査が合格。PDF全15ページを画像化し目視確認。
- 実アプリの新規試験、Igor実行、実測比較、性能測定、クリーンPC試験は未実施。
- 既存独立版v0.1.0は再利用候補。未追跡v0.1.1は変更せず完成版扱いしない。
- 数値許容差と性能値は提案であり、実装前に基準セットで確定する。
