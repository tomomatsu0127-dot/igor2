# v1.2.9 更新案内 — 図のサイズと凡例

- 新規完成図のプロット範囲は幅16×高さ12 cm、Width mode / Height modeともAbsolute。Igor内部では453.543307×340.157480 ptです。軸ラベルと凡例の余白はこの寸法に含みません。
- 凡例の列間隔を実際の文字幅で決めます。日本語・下付き数字のUTF-8バイト数による過大な余白を廃止しました。
- 凡例は1ボックスのまま、各項目を `\s(int_M_type_003) M-type` のようにします。Times New Romanと文字サイズの共通指定は先頭の1回だけです。下付き数字はUnicode文字のまま編集できます。
- 新しく作成/明示更新する完成図の同定マークには `int_相名_試料番号` のトレース名を付けます。重複時は末尾に番号を加えます。科学データのWave名・同定ID・参照番号は変更しません。

## 更新と操作

旧版とExperimentのバックアップを保持し、v1.2.9一式を独立フォルダに配置してください。旧版のxrd_main.ipfを閉じ、新版のxrd_main.ipfだけを読み込んでコンパイルします。旧新版を同時に読み込まないでください。

新しい作図下書きの幅・高さを最初の1回だけ16×12 cmへ設定します。その後に利用者が変更した値は保持します。保存済み図の寸法や手編集は、開くだけでは変更しません。旧図へ今回の書式を反映する場合は複製で『この図のサイズと凡例を更新』または作図設定の反映を行います。明示的な書式更新は凡例本文を再生成するので、手編集を残す場合は先に別名で保存してください。

凡例はダブルクリックして編集できます。色・記号だけの更新、ネイティブ図の再表示、保存・再起動では手編集した本文を保持します。端をドラッグして自由に伸縮する場合は『この図を端のドラッグで伸縮できるようにする』を押すとAutoへ切り替わります。

相の短い呼び名は、参照ライブラリの『表示名』をM-typeなどに揃える方法を推奨します。化学式から相を推測して自動で改名しません。

Experimentは必ず新しい名前で保存し、再起動して確認してください。外部Procedureの参照先となる新版フォルダは残してください。本作業では利用者のQSや添付PXPを上書きしていません。
